## Summary

For a fixed architecture, BiU-Net processes a genotype matrix by segmenting each sample into overlapping windows. Let N be the number of training samples, P the number of SNPs, L the segment length, O the overlap, and S = L - O the stride. The number of training examples per epoch is approximately N x ceil(P/S), so training and inference scale approximately linearly with both sample size and SNP count for fixed L and O. The model-level table above reports parameter counts and per-segment forward-pass MAC/FLOP estimates computed from the actual PyTorch modules used in this study.
